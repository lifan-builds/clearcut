## Project guidance

- **Repository & workspace boundaries:** Clearcut is the multi-catalog specialist deal engine powering FreshPowder, Big Ring, and Bench Drop. `common/deal_common/` owns category-independent models, parsers, HTTP traversal, rate limiting, and shared catalog storefront runtime (must never import a catalog). `catalogs/fresh-powder/` (`src/aggregator/`) owns Fresh Powder, `catalogs/cycling/` (`src/cycling_deals/`) owns Big Ring, and `catalogs/tools/` (`src/tool_deals/`) owns Bench Drop.
- **Ranking & variant integrity:** Rank strictly by unrounded percentage off first (`docs/METHODOLOGY.md`); reviews, images, and commissions never outrank discount depth. Select a matching variant before filtering, sorting, counting, and pagination so sale price, reference price, size, stock status, and purchase URL agree; unknown stock never satisfies an exact-size filter.
- **Setup & offline verification:** Install once from root with `.venv/bin/python -m pip install -e '.[dev]'`. Run `.venv/bin/python scripts/check.py -q`, `.venv/bin/ruff check .`, and `node --test catalogs/fresh-powder/tests/*.cjs`.
- **Safety & operations:** Keep web serving read-only against bundled SQLite snapshots (`vercel.json` -> `scripts/vercel_build.py` -> `api/index.py`). Data refreshes are manual (`workflow_dispatch` only; never add automatic cron schedules). Never read, stage, mutate, or publish ignored credentials, browser state, deployment state, or local database files during validation.
